# deskgit 0.8.3

- **Create a pull request from one form**: press `o` on a branch, on GitHub, and one menu holds the whole pull request. Title, description (in your editor), base, reviewers (people and teams), assignees, labels and GitHub Projects, each with a key (t, e, b, r, a, l, p). Then press `c` to create, or `d` to create it as a draft. Pickers tick several and stay open until you choose Done
- **Filled in for you**: the task's code and title as the title, the repository's PR template or the list of commits as the description, a link to the task, and the repository's default branch as the base
- **Nothing is lost by accident**: Esc asks before throwing away a filled-in form, and the form comes back if your editor exits with an error. A pull request from a branch into itself is stopped with a message, not an error from GitHub
- **GitHub Projects** need one extra permission: run `gh auth refresh -s project` once. Until then the Projects row says so, and the rest of the form works
