# deskgit 0.8.5

- **Pick the GitHub account for each repository**: with more than one account signed in to gh, `o` asks once which account a repository uses, and the repository remembers it. The pull request form shows the account and changes it with `g`. Merging and the pull request shown beside each branch use the same account
- **"Not Found" explained**: when GitHub cannot find the repository, deskgit says which repository and as which account, and offers to pick another
- **`o` on a branch with an open pull request** shows that pull request (open in browser, copy link, merge in deskgit) instead of the create form
- **`O` is removed**: the old menu of pull request options. Everything it did is on `o`
