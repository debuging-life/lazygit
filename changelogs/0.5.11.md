## deskgit 0.5.11

### New features

- **Recently created task floats to top** — after creating a task from within deskgit, it appears pinned at the top of the task picker under a "Just created" section header for the rest of the session.

### Bug fixes

- **Actionable error for unrecognized remotes** — instead of the cryptic "Unsupported git service" message, deskgit now shows a clear explanation with the exact lazygit config snippet needed to fix SSH config alias remotes (e.g. `git@github-work:owner/repo.git`).
