# deskgit 0.8.6

- **The GitHub account picker in the HUD look**: each account on a number key (1–9), the login in bold, and a tag: `◆ THIS REPO` for the account this repository uses, `● ACTIVE IN GH` for gh's active one, the rest dim. The question names the repository, and the frame's title says why it is asked (switching, or a repository not found)
- **Esc or Cancel on the account picker goes back to the pull request form**, keeping what you typed
- **After "not found"**, the account that could not see the repository is marked `CAN'T SEE IT`, and the picker starts on another
