# deskgit 0.8.1

Commits now show on DeskTick's task cards.

- **Each commit is told to DeskTick as it is made**: its message, author, time, and the paths and line counts of the files changed, never the code itself. A commit made offline or signed out waits in the repository and goes on the next push, or within a minute of deskgit being open. deskgit updates the hooks of linked repositories by itself; elsewhere it asks again
- **Rebases, cherry-picks and reverts are left alone**: replayed commits are no longer tagged with the picked task, and `fixup!`, `squash!` and `amend!` messages keep their shape
- **"fix utf-8 decoding" gets the task code**: a lowercase word with a number is no longer taken as a task code already in the message. A lowercase code in a branch name (`feature/clk-12-timer`) still counts when pushing
- Repositories that use `core.hooksPath` (Husky and the like) need `dt-hook post-commit` added beside the other two hooks
