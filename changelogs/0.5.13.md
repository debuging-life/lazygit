## deskgit 0.5.13

### New features

- **Setup repository remote** — the DeskTimers menu (`alt+d`) now includes "Setup repository..." (`s`). If no remote exists you'll be prompted for a name and URL; if remotes are already configured you can pick one to update its URL or add a new one. Changes take effect immediately and the remotes panel refreshes automatically.

### Bug fixes

- **"Unsupported git service" now shows the correct config path** — the dialog now displays the actual path deskgit reads its config from (on macOS this is `~/Library/Application Support/deskgit/config.yml`, not `~/.config/deskgit/config.yml`). The toast after copying the snippet also references the correct file, so you know exactly where to paste it.
