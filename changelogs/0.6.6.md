## deskgit 0.6.6

### Bug fixes

- **Create PR now shows a progress spinner** — the "Creating pull request…" message now animates while the GitHub API call is in flight (previously it was blocked by the UI thread and never rendered).
- **Merge PR now shows a progress spinner** — selecting a merge strategy now shows "Merging pull request…" while the API call runs, instead of freezing the UI silently.
