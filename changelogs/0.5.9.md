## deskgit 0.5.9

### New features

- **In-app PR create** — press `O` on any branch to open the PR options menu; a new "Create pull request (in-app)" entry lets you set the title, base branch, and description without leaving the TUI. The PR is created via the GitHub REST API (requires `gh auth login`) and opens in the browser once created.
- **In-app PR merge** — the same `O` menu shows a "Merge PR #N" entry for branches that already have an open pull request. Choose between merge commit, squash-and-merge, or rebase-and-merge.
