# deskgit 0.7.2

- **PR merge — column picker**: when merging a PR linked to a DeskTimers task, deskgit now shows all project columns before the merge so you can choose exactly where the task goes (or keep it in its current column)
- **Webhook race fixed**: the suppress-done flag is sent to the backend *before* the GitHub merge call, so the webhook can never beat the user's choice
- **Timer auto-stop**: moving a task out of an in_progress-role column via the merge dialog now stops the active timer
