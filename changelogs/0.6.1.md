## deskgit 0.6.1

### New features

- **Setup repository remote** — the DeskTimers menu (`alt+d`) now includes "Setup repository..." (`s`). If no remote exists you'll be prompted for a name and URL; if remotes are already configured you can pick one to update its URL or add a new one.
- **All PR creation is now in-app** — "dev → Default branch" and "dev → Select branch" in the `O` menu now go through the GitHub API directly (no browser form). Title and description are pre-filled from your last commit message. A "Creating pull request..." spinner shows while the API call is in flight.
- **Merged PRs no longer appear in the merge menu** — "Merge PR" items only show when the PR is still open, grouped under a "Pull requests" section header.

### Bug fixes

- **Clear error when creating a PR from a branch to itself** — instead of a cryptic "Validation Failed", deskgit now blocks the call immediately and shows a plain-English explanation.
- **"Unsupported git service" shows the correct config path** — on macOS the dialog now shows `~/Library/Application Support/deskgit/config.yml` (the file deskgit actually reads) instead of `~/.config/deskgit/config.yml`.
