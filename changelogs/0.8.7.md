# deskgit 0.8.7

- **Edit an open pull request from `o`**: the same form, filled from GitHub. Only what you changed is sent; `d` saves and marks a draft ready, or turns it back into a draft
- **Marks beside a branch with a pull request**: `!` conflicts, `✗` changes asked for, `✓` approved. `o` says the same in words
- **Tidy up after a merge**: switch to the base, delete the branch here and on GitHub, pull. A branch with commits GitHub does not have is kept, and you are told why
- **Pull requests show on their DeskTick task at once**: made, edited or merged from deskgit
- **No column question before a merge**: DeskTick moves the task when GitHub says the pull request merged
- **Windows**: `irm https://cdn.desktimers.com/install.ps1 | iex` installs deskgit, and `deskgit update` works there. The sign-in link opens in full
