## deskgit 0.6.8

### New features

- **Confirm before moving task to Done on PR merge** — after merging a pull request, deskgit now asks "Move DESK-293 to Done?" A task linked to multiple repos (API, webapp, etc.) can stay open until all sides are merged. If you choose Yes, deskgit calls the DeskTimers API to mark the task done. If you choose No, the task is left in its current state.
