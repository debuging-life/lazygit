## deskgit 0.7.0

### Bug fixes

- **"Move to Done?" now reliably appears on every PR merge** — fixed two bugs:
  1. The task code is now resolved from three sources in order: head branch name → PR title → currently selected task. Previously if the second PR's branch didn't contain the task code the prompt was silently skipped.
  2. Fixed the menu not appearing on second invocation by properly returning the `Menu()` call result instead of discarding it.
