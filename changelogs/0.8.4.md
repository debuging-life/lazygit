# deskgit 0.8.4

- **SSH aliases are recognised**: a remote written through a Host alias in `~/.ssh/config` (for example `git@github-work:acme/clock.git`, the usual way to use two GitHub accounts) is now read as the service the alias points to. `o` opens the pull request form on such a repository with no `services` setting; deskgit asks `ssh -G` once per alias
- `ssh.github.com` and `altssh.gitlab.com`, the port 443 hosts, count as GitHub and GitLab
